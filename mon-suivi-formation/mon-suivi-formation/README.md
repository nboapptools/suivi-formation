# Mon suivi de formation — version de départ

Application web personnelle, sans installation ni serveur.

## Démarrer en local
1. Décompresser le dossier.
2. Ouvrir `index.html` dans un navigateur (Chrome, Edge ou Firefox).
3. Les données sont enregistrées dans le stockage local du navigateur.

## Mise en ligne gratuite avec GitHub Pages
1. Créer un compte GitHub si nécessaire.
2. Créer un dépôt public nommé `suivi-formation`.
3. Ajouter le fichier `index.html` à la racine du dépôt.
4. Dans Settings > Pages, choisir `Deploy from a branch`, branche `main`, dossier `/ (root)`.
5. Enregistrer. GitHub affichera l'adresse du site après publication.

## Fonctionnalités
- Tableau de bord 460 h / 6 mois.
- 14 chapitres préremplis avec 7 séquences chacun (modifiables de 5 à 10).
- Statuts À faire / En cours / Terminé.
- Workshops 1 et 2 terminés, workshop 3 en cours.
- Journal des heures réalisées.
- Export et import JSON de sauvegarde.

## Limite de cette première version
Les données sont stockées dans le navigateur utilisé. Le site peut être ouvert sur plusieurs appareils, mais les données ne se synchronisent pas automatiquement. Pour cela, une deuxième version avec authentification et base de données sera nécessaire.
